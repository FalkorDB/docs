Every FalkorDB Enterprise release pins the versions below. Installing a release
installs exactly these subcharts, so pick the Enterprise version rather than
pinning subcharts individually.

## Release channels

<CardGroup cols={3}>
  <Card title="stable" icon="circle-check">
    The current recommended release, and what a default install gets. Use this
    unless you have a reason not to.
  </Card>
  <Card title="beta" icon="flask">
    Early access to new capabilities. Not covered by production support.
    Published as prerelease versions such as `0.5.0-beta.1`, so a default
    install never picks one up.
  </Card>
  <Card title="lts" icon="shield">
    Long-term support. Receives fixes for an extended window and is the target
    for conservative upgrade policies.
  </Card>
</CardGroup>

Install the latest stable release by omitting `--version`. To try a beta, pass
`--channel beta`, or name the exact version:

```bash
curl -fsSL https://falkordb.github.io/FalkorDB-Enterprise/install.sh | \
  bash -s -- \
    --registry-username '<username>' \
    --registry-password '<token>' \
    --channel beta
```

## Tested upgrade paths

Moving a deployment to a newer FalkorDB addon release replaces its definition in one
step: nothing an addon release in between would have done runs. So CI upgrades to each
release from the newest release of every addon version a supported release shipped,
with databases running. The chart upgrade must leave them untouched; each database is
then [moved to the new addon release](/enterprise/upgrades/addon) and upgraded to the newest
FalkorDB version, and must keep its data and topology.

Upgrades to `1.0.0-beta.6` are tested from:

| From Enterprise | FalkorDB addon before | FalkorDB addon after |
| --- | --- | --- |
| `1.0.0-beta.5` | `1.7.13` | `1.7.15` |
| `1.0.0-beta.4` | `1.7.7` | `1.7.15` |
| `1.0.0-beta.3` | `1.7.5` | `1.7.15` |

A release not listed that ships the same addon as a listed one makes the same addon
jump. Upgrade a release older than `1.0.0-beta.1` to `1.0.0-beta.1` first, following
the [migration guide](/enterprise/upgrades/migrations/0.3-to-1.0).

## Admin components

The Admin Server, Admin UI, and Admin CLI images are tagged with the Enterprise
chart version. Chart `0.4.1` runs Admin Server `0.4.1`, and so on.
