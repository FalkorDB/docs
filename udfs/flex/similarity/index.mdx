FLEX similarity utilities.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What are FLEX similarity functions?">
    FLEX similarity functions compute metrics that measure how alike two values are. Currently this includes the Jaccard coefficient for set similarity.
  </Accordion>
  <Accordion title="When should I use similarity functions vs text distance functions?">
    Use `flex.sim.jaccard` for comparing **sets** (like tags or interests). Use `flex.text.levenshtein` or `flex.text.jaroWinkler` for comparing **strings** character by character.
  </Accordion>
  <Accordion title="How do I call a similarity function?">
    Use the namespace `flex.sim.<function>()`. For example: `flex.sim.jaccard(['a','b'], ['b','c'])` returns `0.333`.
  </Accordion>
</AccordionGroup>
