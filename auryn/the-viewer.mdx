---
title: "The Auryn Viewer: Explore Your Code Graph in the Browser"
sidebarTitle: "The viewer"
description: "auryn view opens a local browser explorer over the same graph your agent uses — search symbols, expand neighbors, trace paths, and color the graph by subsystem."
---

`auryn view` opens a browser explorer over the same graph your agent uses. Search for a symbol, expand its neighbors, find the path between two things, and color the graph by the subsystems it detects. It listens on localhost only.

```bash
auryn view
```
