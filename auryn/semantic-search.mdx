---
title: "Semantic Search in Auryn"
sidebarTitle: "Semantic search"
description: "auryn embed adds a local search index over each function's code and docs, so search_code can find a symbol by what it does when the name is unknown."
---

Sometimes your agent doesn't know what a thing is called. `auryn embed` adds a search index over each function's code and docs, so [`search_code`](/auryn/agent-tools) can find it by what it does. It's optional, and the embedding model runs locally.

```bash
auryn embed              # only new symbols are processed
auryn embed --reembed    # rebuild after changing the model
```
