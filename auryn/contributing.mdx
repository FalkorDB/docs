Auryn is open source and new languages are very welcome. Each language is its own small package, so adding one never means touching the core.

```bash
git clone https://github.com/FalkorDB/Auryn && cd Auryn
uv sync --group dev
uv run pytest --cov=auryn --cov-report=term-missing
```

Tests run against an embedded FalkorDB, so you don't need a server or Docker.
