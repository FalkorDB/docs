Your code stays yours.

<CardGroup cols={2}>
  <Card title="Runs where you do" icon="server">
    On your machine or your own FalkorDB. No hosted service, no telemetry.
  </Card>
  <Card title="Read tools can't write" icon="lock">
    Read tools only issue read-only queries the database enforces; only the two indexing tools build the graph.
  </Card>
  <Card title="Your repo stays clean" icon="broom">
    Install touches only your Auryn home (`~/.auryn` by default) and your agent's config — never your repository.
  </Card>
  <Card title="Local only" icon="location-dot">
    The bundled database and the viewer listen on localhost.
  </Card>
</CardGroup>

## Uninstall

Install records everything it changed, and uninstall reverses exactly that.

```bash
auryn uninstall            # keeps your graphs
auryn uninstall --purge    # also deletes ~/.auryn and the graphs it holds
```
