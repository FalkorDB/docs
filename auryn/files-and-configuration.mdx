Almost everything Auryn keeps is in one folder in your home directory — the exception is `quickstart`, which keeps its graph beside the code.

| Path | Purpose |
| :--- | :--- |
| `~/.auryn/config.toml` | Your backend, refresh trigger, ingested repositories, and disabled hooks. |
| `~/.auryn/store.db` | The local database: every graph, index, and embedding. |
| `~/.auryn/hooks/` | Your own [hooks](/auryn/hooks). |
| `<repo>/.auryn/graph.db` | Only for `quickstart`, which keeps its graph beside the code. |

## Environment variables

| Variable | Effect |
| :--- | :--- |
| `AURYN_HOME` | Use a different folder instead of `~/.auryn`. |
| `AURYN_AUTO_INSTALL=0` | Don't download the local embedding model automatically. |
