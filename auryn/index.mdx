Auryn turns a codebase into a knowledge graph of its functions, types, tables, and endpoints, and the connections between them. It stores that graph in [FalkorDB](https://www.falkordb.com) and hands it to your coding agent, so the agent answers from how your code actually fits together.

It works with Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, Gemini CLI, and any other MCP client, reads fifteen languages plus live SQL and Oracle schemas, and runs entirely on your machine.

## Why Auryn

- **Graph-grounded answers.** Your agent reasons over real call graphs, inheritance, endpoints, and table access instead of guessing from a handful of open files.
- **Fifteen languages, one vocabulary.** Every language writes into the same [graph model](/auryn/graph-model), so "who calls this" works the same in Go as in C#.
- **Fast, incremental refresh.** Auryn never rebuilds from scratch — each refresh updates only what changed. See [Keeping it fresh](/auryn/keeping-it-fresh).
- **Local and private.** No hosted service and no telemetry. See [Privacy & security](/auryn/privacy-and-security).

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What is Auryn?">
    Auryn is a FalkorDB-powered tool that indexes a codebase into a knowledge graph of functions, types, tables, and endpoints, and exposes it to coding agents over the Model Context Protocol (MCP). Your agent queries the graph to answer questions about how your code fits together.
  </Accordion>
  <Accordion title="Which coding agents does Auryn support?">
    Auryn registers itself with Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, VS Code Copilot Chat, Gemini CLI, and Antigravity. Aider and `AGENTS.md`-aware agents get written instructions instead, and any other MCP client can be pointed at the server manually. See [Connect your agent](/auryn/connect-your-agent).
  </Accordion>
  <Accordion title="Does Auryn send my code anywhere?">
    No. Auryn runs on your machine against a bundled FalkorDB or your own instance, with no hosted service and no telemetry. Read tools only ever issue read-only queries. See [Privacy & security](/auryn/privacy-and-security).
  </Accordion>
  <Accordion title="Do I need to run a server or Docker?">
    No. Quickstart starts an embedded FalkorDB for you. You can also point Auryn at a FalkorDB you already run. See the [Quickstart](/auryn/quickstart).
  </Accordion>
</AccordionGroup>
