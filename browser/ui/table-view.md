# Table View

Table view shows query results as rows and columns.

## Behavior

- Headers derive from union of row keys
- Search/filter and expand/collapse interactions
- Scroll state and expand state are preserved in table context

## Export

Table view can export current data to CSV.

## Settings impact

Table rendering uses configured column width and row height settings.
