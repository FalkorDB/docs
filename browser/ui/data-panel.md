# Data / Property Panel

Data panel appears when selecting a node or edge.

## Shows

- Element ID
- Labels (node) or type (edge)
- Property table

## Node label actions

- Add label
- Remove label

## Editing behavior

Property and label edits call graph APIs and update graph/canvas state.

## Close behavior

- Close button
- Escape key
