# Graph Page (Layout)

The Graph page (`/graph`) is Browser's main workspace.

## Layout

1. Left sidebar navigation
2. Top workbar (Graph Info toggle, Upload, Editor, History, Chat)
3. Center results tabs (Graph / Table / Metadata)
4. Right contextual panel (Graph Info / Data / Add / Chat)

## Panel behavior

- Element selection opens Data panel
- Add Node/Add Edge opens create panel
- Chat toggle opens chat panel
- Graph Info toggle opens graph metadata panel

## Background refresh

Graph metadata polls periodically (labels, relationships, property keys, counts, optional memory).
