# Style Panel

Style panel customizes visual style for one label.

## Editable properties

- Color (preset or custom picker)
- Size

## Behavior

- Changes preview immediately on canvas
- Save persists style
- Cancel/Escape reverts to original style

## Scope

Label style persistence is tied to Browser local storage context.
