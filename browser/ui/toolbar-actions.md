# Graph Toolbar & Element Actions

Toolbar is the canvas overlay for search and editing actions.

## Search

Search supports matching:

- Property values
- IDs
- Relationship types
- Labels

Selecting a suggestion updates selection and focuses the matched area.

## Editing actions

For non-read-only users:

- Add Node
- Add Edge (selection-dependent)
- Delete selected elements

## Informational hints

Toolbar can show warnings such as result limit reached or rerun-needed configuration changes.
