# Navigation & Header

Browser uses a left sidebar for primary navigation and global actions.

## Primary routes

- Graphs (`/graph`)
- Settings (`/settings`)
- UDF (`/udf`) when available

## Global controls

- Help menu (docs, API docs, support, about)
- Theme cycle (`dark`, `light`, `system`)
- Logout all

## Connection controls

- Select active connection
- Add connection
- Remove single connection

If the last connection is removed, Browser performs full sign-out.
