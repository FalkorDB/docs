# Query History

Query History stores executed queries and related metadata.

## Features

- Search and filtering
- Graph-based filtering
- Favorites
- Re-run historical query
- View stored metadata/explain/profile
- Delete selected or all history entries

## Storage

History is saved in Browser local storage scoped to the active connection context.
