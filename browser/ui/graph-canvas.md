# Main Graph Canvas

Graph tab renders query results as an interactive node/edge canvas.

## Core interactions

- Pan and zoom
- Zoom in/out and zoom-to-fit
- Select node or edge
- Multi-select workflows

## Layout and view controls

- Layout mode (`force`, `tree`, `radial`)
- Direction options for tree/radial
- Animation toggle
- Pin-on-drag toggle
- Focus/dim toggle

## Selection-driven behavior

- Selection syncs with Data panel
- Two-node selection enables Add Edge flow
- Search result selection auto-focuses canvas
