# Graph Info Panel

Graph Info is a side panel for structural graph inspection and quick query actions.

## Contents

- Graph selector
- Create graph action (if permitted)
- Optional memory metric
- Node count and labels
- Edge count and relationship types
- Property keys

## Actions

- Query all nodes/all relationships
- Query by label/type
- Query by property key existence
- Open Style panel for label customization

## Search behavior

Inline search inputs appear when section size exceeds configured threshold.
